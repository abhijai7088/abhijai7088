## 🚀 Architectural Evidence & Deployments

### 🥇 [Phoenix — Autonomous CI/CD Healing Agent](https://phoenix-ci-dashboard.vercel.app/)
**AI Agents · LangGraph · Docker Sandboxing · FastAPI**
An AI-powered repository repair engine that autonomously analyzes GitHub repositories, tests them in isolated environments, and iteratively commits verified LLM-generated patches.
* **Architecture Proof:** Designed a 7-stage agentic workflow (Repo Analyst → Test Runner → Failure Parser → Fix Planner → Code Editor → Git Operator → Verifier).
* **Execution:** Executed tests inside Docker-isolated ephemeral environments with strict memory constraints to ensure secure sandboxing.
* 🔗 [Live Dashboard](https://phoenix-ci-dashboard.vercel.app/) | 📡 [API Docs](https://autonomous-ci-cd-healing-agent-c6vj.onrender.com/docs) | 💻 [Source](https://github.com/abhijai7088/Autonomous-CI-CD-Healing-Agent)

### 🏛️ [INHERIX — Digital Continuity Platform](https://www.inherix.net)
**SaaS · Secure Data Architecture · Next.js · PostgreSQL · AWS**
A deployment-ready SaaS platform structured around digital vaults, records, and controlled access workflows for trusted advisors.
* **Architecture Proof:** Built an API-driven backend architecture with Role-Based Access Control (RBAC), secure vault logic, and PostgreSQL data modeling.
* **Infrastructure:** Deployed via AWS S3 for object storage, Nginx reverse proxying, and secure Linux server administration.
* 🔗 [Live Website](https://www.inherix.net) | 📱 [Live Application](https://app.inherix.net)

### 🏥 [AI-CMS — Clinic Management Platform](https://cms.ott-tube.in/)
**Hybrid Backend · RBAC · AI APIs · Docker**
A full-stack clinic management system combining operational workflows with AI-assisted processing (OCR, STT, LLM formatting).
* **Architecture Proof:** Designed a separated service architecture utilizing an Express.js API for strict JWT-based auth/RBAC, alongside a dedicated Python FastAPI service for isolated AI workloads.
* **Deployment:** Containerized the complete multi-service stack using Docker Compose on an Ubuntu VPS.
* 🔗 [Live Deployment](https://cms.ott-tube.in/) | 💻 [Source](https://github.com/abhijai7088/clinic-management-ai-cms)

### 👁️ [AI-Based Lost Person Tracking System](https://github.com/abhijai7088/AI-Based-Lost-Person-Tracking-System)
**Computer Vision · Person Re-ID · Video Analytics**
A pipeline designed to locate missing persons through CCTV footage by chaining multiple specialized computer vision models.
* **Architecture Proof:** Engineered a sequential processing pipeline: Face Detection (`RetinaFace`) → Embeddings (`ArcFace`) → Person Detection (`YOLOv8`) → Tracking (`ByteTrack`) → Re-Identification (`OSNet`).
* 🏆 **Hacknovate 6.0 Finalist** | 🥈 **SuperNova Hackathon 2nd Prize**
